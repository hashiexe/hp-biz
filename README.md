# hp-biz

接骨院・整骨院向けホームページ制作の営業用リポジトリです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 準備中の簡易ページ（本格的な営業トップは未制作） |
| `samples/sakura-sekkotsuin/` | 制作事例（デモサイト）。架空の院名・住所を使用 |
| `specs/` | 過去の仕様書（旧価格・旧屋号を含むため参考情報） |

## 注意

- `specs/sales-top-fix-spec.md` は旧価格・旧屋号（あおい制作所）を前提に書かれた過去の仕様書です。
  現在は無効。新しい営業トップは別途設計します
